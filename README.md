# 听声辨位 SoundCompass

用手机双麦克风判断声音来自哪个方向的 Android 应用。**哪个方向有声音，罗盘的指针和光束就指向那个方向；声音越大，光束和指针越长。**

## ⚠️ 当前状态（2026-09-18 实测）

应用能正常安装、运行、申请麦克风权限，但**在小米 13 Pro 上实测没有明显可用的方向指示效果**：罗盘指针基本不随声源移动，或只在「侧面（0°）」附近抖动、乱跳。

**这不是算法 bug，而是手机硬件 / 音频框架的限制：**

- 本方案依赖「两个物理麦克风作为独立的左右声道被应用层采集到」。但市面上绝大多数 Android 手机在普通 `AudioRecord` 立体声模式下，**两路声道实际都来自同一颗主麦克风**（顶部/底部的副麦通常只用于通话降噪，不会作为独立采集通道暴露给应用）。
- 两路信号几乎完全一致 → GCC-PHAT 互相关峰值恒定落在 τ≈0 → 解出的方位角永远接近 0°（正侧 / 正前 / 正后，正好是「不可分辨区」），表现就是「指针不动 / 乱跳」。
- 代码中已优先申请 `UNPROCESSED` 原始音源，但小米 13 Pro 的音频 HAL 仍不把两颗物理麦作为独立立体声对暴露，所以测不出可用的时差。

**结论：在普通消费手机上这条路基本走不通，是预期内的「没效果」。** 真正可行的方向是专用麦克风阵列（例如 ReSpeaker 圆形阵列，固件端直接输出方位角），或能强制指定两路物理麦的定制 ROM / 厂商多麦采集 API。

**想自己验证**：打开 App 的「诊断面板」，看「原始时差 µs」是否基本恒为 0、A/B 两路「电平条」是否完全一致。若是，就坐实了上面的限制——两通道拿到的是同一路信号。

## 原理

Android 手机通常有一对可用麦克风（多为手机顶部 + 底部，部分机型为左右两侧）。两声源到达两个麦克风的时间差（TDOA）与电平差（ILD）共同决定声源在麦克风轴线上的方位。

本应用按以下流程实时估计方位（约 47 帧/秒）：

1. `AudioRecord` 以 48 kHz / 16 bit / 立体声采集，优先申请 `UNPROCESSED` 原始音源，避免系统降噪抹掉通道间时差；
2. 每 1024 帧（约 21 ms）取一段 2048 点汉宁窗数据，对两通道分别做 FFT；
3. 计算互功率谱 `R = A · conj(B)`，做 PHAT 归一化（`R / |R|`）后逆变换，得到广义互相关 GCC-PHAT；
4. 仅在物理可达的时延范围 `±d/c`（如间距 15 cm 时约 ±21 个采样点 / ±437 µs）内寻找相关峰，抛物线插值得到亚样本精度时延 `τ`；
5. 反解方位：`u = τ / (d·fs/c)`，`方位角 = arcsin(u) ∈ [-90°, +90°]`；
6. 相关峰的 z 分数作为置信度；置信度低时改用通道电平差兜底；
7. 在 `u` 空间按「置信度 × 电平」加权做滑动平均，输出稳定方位与离散度。

## 能测什么、不能测什么

- **能测**：声源在这条麦克风轴线上的方位（例如纵向摆放时是「偏顶部 / 偏底部」）。
- **不能测**：正前方与正后方。两个麦克风只能确定一个轴上的方向，圆盘下半部分已标注为「不可分辨区」。
- 想要平面 360° 方位需要 3 个以上麦克风阵列，普通手机硬件不提供。

## 界面说明

| 区域 | 含义 |
| --- | --- |
| 罗盘 | 指针指向声源方位；光束宽度随可靠度收窄；光束与指针长度、辉光半径随响度增大 |
| 方位角 | 当前方位读数，`+` 为 A 端、`-` 为 B 端 |
| 响度 | 当前总电平（dBFS） |
| 可靠度 | 0–1，由相关峰置信度、方位离散度、信噪比合成 |
| A / B 电平条 | 两路麦克风的实时电平与峰值保持 |
| 诊断面板 | 原始时差（µs）、电平差（dB）、相关峰 z 值、采样率、实际音频源 |

## 校准

1. 把手机静置，在任一端的正对着拍一下手，观察指针落在 A 端还是 B 端。
2. 如果指示方向与你认定的物理方向相反，打开「通道互换」开关，或直接点「校准：把当前方向当作 B 端」按钮自动对齐。
3. 如果手机是左右双麦（横握），打开「麦克风轴线为横向」。
4. 若定位跳变明显，可调大「平滑帧数」；若反应迟钝，调小。
5. 「麦克风间距」默认 15 cm，多数手机在 12–17 cm 之间；间距填得越准，角度越准。

## 构建

仓库已配置 GitHub Actions，推送到 `main` 会自动编译 debug APK，并发布到 `latest` release。

```bash
# 本地构建（需要 Android SDK 与 JDK 17）
./gradlew assembleDebug
```

CI 产物下载地址：
`https://github.com/gyaoshi/sound-direction/releases/download/latest/SoundCompass-debug.apk`

## 要求

- Android 8.0（API 26）及以上
- 支持立体声录音的设备（应用会在不支持时给出明确提示）
- 麦克风权限（首次启动时申请）
